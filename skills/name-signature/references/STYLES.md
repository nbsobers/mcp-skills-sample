# Signature Styles and Tuning

## The three styles

| Style | Slant | x-height | Stroke | Look |
|-------|-------|----------|--------|------|
| `flowing` (default) | 0.26 | 36px | 3.4px | Loose, strongly slanted, terminal swash under the name. The everyday signature. |
| `compact` | 0.13 | 32px | 2.9px | Upright, tighter letters, no swash. Fits a narrow form field or a small footer. |
| `bold` | 0.22 | 40px | 5.0px | Heavier ink and a wider hand, with the swash. Reads well when scaled down or printed. |

Pick `compact` when the signature has to fit a fixed-width box, `bold` when it will be
reproduced small or on paper, `flowing` otherwise.

## Colour

Pass any CSS hex colour as the third argument. Defaults to `#1a2b4c`, a dark ink blue.

```
python scripts/sign.py "Ada Lovelace" flowing "#111111" > sig.svg
```

Signatures traditionally read as ink rather than pure black: `#1a2b4c` (blue-black),
`#14213d` (navy), `#2b2b2b` (soft black). Avoid mid-greys, which look faded once scaled
down, and avoid pure `#000000` unless the user asks for it.

## Caption

A muted attribution line is centred beneath the signature, below the descenders and the
swash. It defaults to `Generated by MCP Team` (the `CAPTION` constant at the top of
`scripts/sign.py`). Override it with the fourth argument, or pass `""` to omit:

```
python scripts/sign.py "Ada Lovelace" flowing "#1a2b4c" "Approved by Legal"
python scripts/sign.py "Ada Lovelace" flowing "#1a2b4c" ""
```

It sizes at 0.29 x the x-height, tracked slightly, in the ink colour at 55% opacity, and
the SVG widens if the caption is longer than the signature so it never overflows.

Unlike the signature, the caption is an SVG `<text>` element rather than outlined paths, so
it renders in the viewer's system sans-serif. That is deliberate: a caption falling back to
another sans is harmless, whereas the signature itself must never depend on a font being
installed. If you need the caption to be pixel-identical everywhere (print, PDF), convert
the SVG to PNG at generation time using one of the commands below.

## Tuning beyond the presets

`STYLES` at the top of `scripts/sign.py` maps each name to
`(slant, x-height, weight, wobble, flourish, stretch)`:

- `slant` - shear applied per em of height. 0 is upright, 0.35 is a steep hand.
- `x-height` - pixel size of a lowercase letter. Everything else scales from it.
- `weight` - stroke thickness in pixels. **Keep it near 0.09 x the x-height.** Heavier and
  the bowls of `a`, `o` and `g` fill in and the whole name turns into a blob.
- `wobble` - per-letter drift and size variation. 0 is mechanical; above 0.06 looks unsteady.
- `flourish` - whether to sweep a swash back underneath the name.
- `stretch` - horizontal scale on letters only, not on the gaps. Raise it to open up the
  letterforms, lower it to crowd them.

Downstrokes are drawn heavier than cross-strokes automatically (the pen outline widens with
vertical motion), so no pressure setting is needed.

## Converting to PNG

The SVG is the deliverable. If a raster image is needed:

```bash
# macOS, no install required
qlmanage -t -s 1200 -o . signature.svg      # writes signature.svg.png

# librsvg, cleanest result
rsvg-convert -w 1200 signature.svg > signature.png

# headless Chrome
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --screenshot=signature.png --window-size=1200,400 signature.svg
```

For a transparent background leave the SVG as-is: it paints no background rectangle, so
only the ink is drawn.
